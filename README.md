- 인터랙티브 체험(날짜 전환, 그림 위 이름표 클릭, 패널 열림)은 그대로입니다.

- 그림은 그날의 대화와 작업을 상징하도록 AI로 생성한 장면이며, 실제 장소를 촬영한 사진이 아닙니다.
